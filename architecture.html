⑦ ALGORITHMS USED
01

Haar Cascade Classifier

Detects face in frame using sliding window + pre-trained XML model. Calculates attention from face position.

Computer Vision · OpenCV
02

Deep CNN — Emotion Recognition

DeepFace runs VGG/FER+ neural network. Extracts facial features layer by layer. Softmax outputs 7 emotion probabilities.

Deep Learning · DeepFace
03

Rule-Based Expert System

Lookup table maps emotion → cognitive state. Priority override rules for attention and quiz performance.

Expert System · Rule Engine
04

Finite State Machine (FSM)

3 states: easy ↔ medium ↔ hard. Transitions on every emotion change. Immediate question reload.

Adaptive Learning · FSM
05

Weighted Average Scoring

Engagement = Attention×40% + Performance×30% + Positive Emotions×30%. Live 0–100% score.

Multi-factor Scoring
06

Streak Counter (Boredom)

Counts consecutive sad/disgust detections. Resets on any other emotion. Triggers game at count ≥ 1.

Threshold Detection
07

Filtered Random Selection

Filters by subject + difficulty. Removes answered questions. Random pick from candidates. Resets when all done.

Content Recommendation
08

Circular Buffer (Deque)

Rolling window of last 50 emotion/attention readings. Used for trend analysis and engagement calculation.

Data Structure · collections.deque
